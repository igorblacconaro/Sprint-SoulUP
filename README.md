# 🎮 Solução Gamificação SoulUP

Projeto desenvolvido para a disciplina de **Front-End** da **FIAP**, com foco na criação de uma solução de gamificação para incentivar produtividade, organização e engajamento dos usuários dentro da plataforma SoulUP.

---

## 📌 Sobre o Projeto

A proposta da SoulUP é utilizar elementos de gamificação para tornar a experiência do usuário mais dinâmica, interativa e motivadora.

A plataforma oferece recursos que incentivam o desenvolvimento pessoal e profissional através de:
- metas personalizadas;
- desafios diários;
- sistema de pontuação;
- ranking de usuários;
- recompensas por desempenho.
